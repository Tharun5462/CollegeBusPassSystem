College Bus Pass Management System
Project Description

The College Bus Pass Management System is a web-based application developed using Core Java. It helps college transport administrators manage student information, bus routes, and bus pass records.

Technologies Used
Java JDK 17
HTML5
CSS3
Java HttpServer
Git and GitHub
Modules
Dashboard
Student Management
Bus Route Management
Issue Bus Pass
Pass Records
Valid Passes
Features
Add and manage student details
Add and manage bus routes
Issue bus passes
Automatically calculate pass validity
Display valid and expired passes
Responsive user interface
How to Run
Install JDK 17 or later.
Download or clone this repository.
Open the project folder in the terminal.
Compile the Java program:

javac CollegeBusPassSystem.java

Run the application:

java CollegeBusPassSystem

Open your browser and visit:

http://localhost:8080
